# Frontend

The Fire Bites frontend is a React and Vite application. The complete project documentation, including installation, environment variables, routes, API behavior, real-time updates, payments, and deployment guidance, is available in the repository root:

- [Fire Bites project README](../README.md)

## Frontend commands

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

The frontend expects `VITE_API_URL` and `VITE_GOOGLE_CLIENT_ID` in `frontend/.env`.
